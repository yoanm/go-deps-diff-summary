# markdown

Package markdown provides a builder pattern for generating Markdown and HTML documents
with structured formatting, indentation support, and collapsible sections.

The Builder type is the core of this package, offering a fluent API for constructing
formatted output. It manages indentation levels, line endings, and ensures proper
formatting of headers, tables, and collapsible detail sections.

Example:

```go
builder := markdown.NewBuilder()
builder.Header("My Document", 1, 0)
builder.Header("Section", 2, 0)
builder.WriteLine("Some content", 1)
output := builder.String()
```

Builder Methods:

- String(): Get the complete built content
- Write(): Write raw content (no formatting)
- WriteLine(): Write a line with indentation
- WriteEol(): Write end-of-line marker
- Header(): Create Markdown header (# ## ###)
- Details(): Create HTML <details> collapsible section with callback-based content
- HTMLTable(): Create HTML <table> from row iterator

All methods maintain proper indentation and formatting based on depth parameters.

## Types

### type [Builder](./main.go#L36)

`type Builder struct { ... }`

Builder constructs Markdown and HTML documents with proper indentation and formatting.
It uses a fluent API where methods build up content and return the complete result
via String().

#### func [NewBuilder](./main.go#L50)

`func NewBuilder() *Builder`

NewBuilder creates a new Builder instance with default settings.
The builder starts empty and uses two-space indentation with newline line endings.

Example:

```go
builder := NewBuilder()
builder.Header("Title", 1, 0)
result := builder.String()
```

#### func (*Builder) [Details](./markdown_builder.go#L43)

`func (c *Builder) Details(
    summary string,
    contentBuilder func(c *Builder, indentDepth int),
    opened bool,
    indentDepth int,
)`

Details writes an HTML <details> collapsible section with custom content.
The content is generated by calling the provided contentBuilder callback function,
which receives the builder and current indentation depth.

Parameters:

```diff
- summary: The text displayed in the <summary> element (always visible)
- contentBuilder: A callback function that builds the collapsible content.
  Receives the builder and indentation depth for nested content.
- opened: If true, the details section starts expanded (open attribute).
  If false, the section starts collapsed.
- indentDepth: The indentation level for the <details> tags
```

Example:

```go
builder.Details("Click to expand", func(b *Builder, depth int) {
	b.WriteLine("Hidden content", depth)
}, false, 0)
// Produces: <details><summary>Click to expand</summary>Hidden content</details>
```

#### func (*Builder) [HTMLTable](./html_builder.go#L32)

`func (c *Builder) HTMLTable(rowIterator iter.Seq[[]string], indentDepth int)`

HTMLTable writes an HTML table with rows generated by the provided iterator.
Each row is represented as a slice of cell strings (HTML) and is wrapped in <tr> tags.
The table is wrapped in <table> tags and properly indented.

Parameters:

```diff
- rowIterator: An iterator yielding []string for each row. Each element in the
  slice is treated as pre-formatted HTML content for a table cell (should include
  <td> tags).
- indentDepth: The indentation level for the <table> and <tr> tags
```

Output Format:
The function produces HTML like:

```go
<table>
  <tr><td>A</td><td>B</td></tr>
  <tr><td>C</td><td>D</td></tr>
</table>
```

Example:

```go
builder.HTMLTable(func(yield func([]string) bool) {
	yield([]string{"<td>A</td>", "<td>B</td>"})
	yield([]string{"<td>C</td>", "<td>D</td>"})
}, 0)
```

#### func (*Builder) [Header](./markdown_builder.go#L19)

`func (c *Builder) Header(header string, level int, indentDepth int)`

Header writes a Markdown header with the specified level and indentation.
It creates headers using Markdown syntax (# for H1, ## for H2, etc.) and adds
blank lines before and after for proper Markdown formatting.

Parameters:

```diff
- header: The header text content
- level: Header level (1 = #, 2 = ##, 3 = ###, etc.)
- indentDepth: The indentation level for the header line
```

Example:

```go
builder.Header("Main Title", 1, 0)     // Produces: # Main Title
builder.Header("Section", 2, 0)        // Produces: ## Section
builder.Header("Subsection", 3, 1)     // Produces: (indented) ### Subsection
```

#### func (*Builder) [String](./builder.go#L12)

`func (c *Builder) String() string`

String returns the complete built Markdown/HTML content as a string.
It reflects all Write operations that have been performed on the builder.

Returns:
The complete accumulated content as a string.

#### func (*Builder) [Write](./builder.go#L47)

`func (c *Builder) Write(v string)`

Write appends raw content to the builder without any formatting, indentation, or line endings.
It's useful for writing content fragments that will be combined with other methods.

Parameters:

```go
- v: The raw content string to write
```

Panics:
If an error occurs during string concatenation (very rare with strings.Builder).

#### func (*Builder) [WriteEol](./builder.go#L35)

`func (c *Builder) WriteEol()`

WriteEol writes an end-of-line marker without any indentation.
This appends a newline to the output.

#### func (*Builder) [WriteLine](./builder.go#L27)

`func (c *Builder) WriteLine(line string, indentDepth int)`

WriteLine writes a line of content with automatic indentation and line ending.
It prepends the line with spaces based on indentDepth and appends the end-of-line marker.

Parameters:

```diff
- line: The content to write
- indentDepth: The indentation level (0 = no indent, 1 = 1 indent level, etc.)
```

Example:

```go
builder.WriteLine("Content", 0)  // No indent
builder.WriteLine("Nested", 1)   // One level of indent (2 spaces)
```
